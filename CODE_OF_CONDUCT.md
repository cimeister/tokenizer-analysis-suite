# Code of conduct

## The short version

Be respectful. Assume good faith. Criticise work, not people.

## Scope

This applies to issues, pull requests, discussions, and any other project
space, and to public spaces when representing the project.

## Unacceptable behaviour

Harassment, personal attacks, publishing others' private information, and
sustained disruption of discussion.

## Enforcement

Report concerns to the maintainer via the email on the GitHub profile at
https://github.com/cimeister, or through GitHub's own reporting tools if that
is not appropriate. Reports are handled confidentially. Responses range from a
private word to a ban, according to severity.
